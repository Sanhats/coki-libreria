# Escuadra Software · Gestión inteligente para negocios

Sistema web para la gestión de stock, ventas, cajas y operaciones de negocios.

## Desarrollo

```bash
pnpm install
pnpm dev
```

Copiar `.env.example` como `.env.local` y completar las credenciales de Supabase y del proveedor de correo configurado.

## Estado actual

- Login de administrador y vendedor.
- Dashboard protegido.
- Cierre de sesión.
- Recuperación de contraseña para vendedores mediante enlace temporal por correo.
