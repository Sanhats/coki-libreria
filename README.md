# Coki · Gestión de librería

Sistema web para la gestión de stock, ventas y cajas de Librería Coki.

## Desarrollo

```bash
pnpm install
pnpm dev
```

Copiar `.env.example` como `.env.local` y completar las credenciales de Supabase y Brevo.

## Estado actual

- Login de administrador y vendedor.
- Dashboard protegido.
- Cierre de sesión.
- Recuperación de contraseña para vendedores mediante enlace temporal enviado por Brevo.
